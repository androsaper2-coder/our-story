# حكايتنا ❤️

موقع رومانسي Static مجاني مناسب لـ GitHub Pages.

## قبل الرفع
1. افتح `script.js` وعدّل `START_DATE` لتاريخ بداية علاقتكم.
2. ضع صوركم داخل مجلد `images` بالأسماء:
   - photo1.jpg
   - photo2.jpg
   - photo3.jpg
   - photo4.jpg
   - photo5.jpg
3. عدّل النصوص داخل `index.html` كما تحب.

## رفعه على GitHub Pages
- أنشئ Repository جديد على GitHub.
- ارفع كل الملفات والمجلد `images`.
- Settings → Pages.
- اختر Deploy from a branch.
- اختر `main` و`/root`.
- Save.

بعدها سيظهر رابط GitHub Pages الخاص بالموقع.
